# BIQS Academy Bahawalpur — Educational Website

## 📌 Project Overview
A fully responsive, SEO-optimized, and high-performance static website for BIQS Academy — a premier educational coaching institute in Bahawalpur, Pakistan.

## 🚀 Live Demo
🔗 [https://biqs-academy-bahawalpur.vercel.com](https://biqs-academy-bahawalpur.vercel.com)

## ✨ Key Features
- ✅ 90+/100 Lighthouse Performance Score
- ✅ Fully Responsive (Mobile, Tablet, Desktop)
- ✅ Tailwind CSS (Build-time optimized)
- ✅ SEO Ready (Meta Tags, Open Graph, Structured Data)
- ✅ Security Headers (CSP, X-Frame-Options, etc.)
- ✅ AI/GEO Optimization (llm.txt)
- ✅ Zero Dependencies (No framework, no build tool — pure HTML/CSS/JS)

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (v4 — build-time)
- Vanilla JavaScript
- Font Awesome Icons
- Vercel (Hosting)
