# BIQS Academy Bahawalpur — Educational Website

## 📌 Project Overview
A fully responsive, SEO-optimized, and high-performance **static website** for BIQS Academy — a premier educational coaching institute in Bahawalpur, Pakistan.  

This project was originally developed as a client website (5–6 pages) and later completed and refined as a **personal portfolio project**.

## 🚀 Live Demo
🔗 [https://biqs-academy-bahawalpur.vercel.app](https://biqs-academy-bahawalpur.vercel.app)

## ✨ Key Features
- ✅ Fully Responsive (Mobile, Tablet, Desktop)
- ✅ Tailwind CSS (Pre-built & optimized)
- ✅ SEO Ready (Meta Tags, Open Graph, Canonical, Structured Data)
- ✅ Security Headers (CSP, X-Frame-Options, Referrer-Policy, etc.)
- ✅ AI/LLM Optimization (`llm.txt`)
- ✅ Clean & Semantic HTML5
- ✅ Fast Loading Static Architecture
- ✅ Favicon + Open Graph Image Support
- ✅ Accessible Navigation (Skip to content, ARIA labels)

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (Build-time optimized)
- Vanilla JavaScript
- Font Awesome Icons
- Vercel (Hosting)
